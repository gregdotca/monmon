## How AI Was Used

The maintainer wrote nearly all of monmon's code by hand, starting in 2022, before AI coding agents were used on it. Since 2026, an AI coding agent has made small changes, such as the install script's handling of the Raspberry Pi's address. The maintainer decides what each change should do and reads and checks every line the AI writes before it's committed.

AI-written changes are also reviewed by a second AI, and the two go back and forth until it doesn't find any more issues. That review doesn't change the oversight level. Commits are marked with `Co-Authored-By: Claude Code` and, where Codex reviewed them, `Reviewed-By: Codex`.
